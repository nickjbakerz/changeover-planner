Most common choice

Windows

Normal setup program for a 64-bit Windows computer.

Download for Windows Version 0.8.3 · EXE installer
Windows installation help
  1. Open the downloaded Changeover Planner Setup file.
  2. If Windows says it protected your PC, click More info.
  3. Confirm the app name, then click Run anyway.
  4. Finish setup and search the Start menu for Changeover Planner.

If “Run anyway” is unavailable, that computer may be managed by an organization or using Smart App Control.

Two Mac versions

Mac

Choose the chip shown under Apple menu → About This Mac.

Apple Silicon Mac M1, M2, M3, M4, or newer Intel Mac Macs that say “Intel”
Mac installation help
  1. Open the downloaded DMG and drag Changeover Planner into Applications.
  2. Try to open Changeover Planner once.
  3. If macOS blocks it, open System Settings → Privacy & Security.
  4. Scroll to Security, click Open Anyway, then confirm Open.

About the security warning

Yes, your computer may show a warning.

Changeover Planner is a small, free alpha project made by Nick Baker. These test builds are not yet signed or notarized through paid Apple and Microsoft developer programs. The warning means the computer cannot verify the publisher’s identity—it does not automatically mean the computer found malware.

Only download the app from this official page. The source code is public, every file comes directly from the project’s official GitHub release, and your camp information stays on your computer.
